# OpenGL / GLUT / FreeGLUT Complete Tutorial

A complete interactive reference guide for Computer Graphics with OpenGL, GLUT, and FreeGLUT.

## Features
- All OpenGL + GLUT + FreeGLUT functions with deep explanations
- Computer Graphics fundamentals (CG concepts)
- Category-wise function listing with dropdown explanations
- Complete working code examples
- Bengali language explanations

## Live Demo
Hosted on Netlify — deploy from this repo.

## Local Development

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

## Deploy to Netlify

1. Push this repo to GitHub
2. Go to [netlify.com](https://netlify.com) → "Add new site" → "Import from Git"
3. Select your repo
4. Build command: `npm run build`
5. Publish directory: `dist`
6. Click Deploy!

Netlify will auto-detect the `netlify.toml` config.
