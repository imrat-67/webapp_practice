Clustering & PCA

এই অধ্যায়ে আমরা Unsupervised Learning-এ ঢুকছি — এখানে কোনো "সঠিক উত্তর (y/label)" দেওয়া থাকে না। Model নিজে থেকেই data-র মধ্যে pattern/গঠন খুঁজে বের করে।

KMeans — Data-কে দলে ভাগ করা

clustering
KMeans
from sklearn.cluster import KMeans

Data point-গুলোকে K-টা group/cluster-এ ভাগ করে, এমনভাবে যাতে একই cluster-এর point-গুলো একে অপরের কাছাকাছি থাকে, আর ভিন্ন cluster-এর point-গুলো দূরে থাকে।

ইনটুইশন: ধরো, তোমার কাছে হাজারটা customer-এর কেনাকাটার data আছে, কিন্তু কোনো "label" নাই (কে "high-value", কে "low-value" — এটা কেউ বলে দেয়নি)। KMeans নিজে থেকেই খুঁজে বের করবে কোন কোন customer একই রকম আচরণ করছে, আর তাদের একটা group-এ ফেলবে।
Parameterমানে
n_clustersকয়টা group/cluster বানানো হবে (এটা আগে থেকেই ঠিক করে দিতে হয়)
random_stateReproducibility-এর জন্য fixed সংখ্যা
from sklearn.cluster import KMeans

model = KMeans(n_clusters=3, random_state=42)
model.fit(X)

labels = model.labels_          # প্রতিটা point কোন cluster-এ পড়লো (0, 1, 2...)
centers = model.cluster_centers_ # প্রতিটা cluster-এর কেন্দ্রবিন্দু
সঠিক K কীভাবে বাছাই করবো? সাধারণত Elbow Method ব্যবহার হয় — বিভিন্ন K-এর জন্য error (inertia) plot করে, যেখানে improvement হঠাৎ কমে যায় (কনুই/elbow-এর মতো বাঁক), সেই K-টা বেছে নেওয়া হয়।

PCA — অনেক feature-কে কম feature-এ সংক্ষিপ্ত করা

dimensionality reduction
PCA
from sklearn.decomposition import PCA

যদি তোমার data-তে অনেক (যেমন ১০০টা) feature থাকে, PCA সেগুলোকে কম সংখ্যক (যেমন ২টা) নতুন feature-এ রূপান্তর করে, যেগুলো original data-র সবচেয়ে বেশি variation/তথ্য ধরে রাখে।

ইনটুইশন — ছায়া (shadow) দিয়ে বুঝি: কল্পনা করো, একটা 3D বস্তুর (যেমন একটা কাপ) ছায়া (2D) ফেলছো দেয়ালে। সঠিক angle-এ আলো ফেললে, ছায়া থেকেই বস্তুর আকৃতি অনেকটা বোঝা যায় — যদিও তথ্য কমে গেছে (3D থেকে 2D), তাও সবচেয়ে গুরুত্বপূর্ণ shape-টা টিকে আছে। PCA ঠিক এই কাজটাই করে, high-dimension data-র জন্য।
Parameterমানে
n_componentsকয়টা নতুন feature-এ কমাতে চাও (যেমন 2, visualization-এর জন্য)
from sklearn.decomposition import PCA

pca = PCA(n_components=2)
X_reduced = pca.fit_transform(X)  # ১০০টা feature থেকে মাত্র ২টায়

print(pca.explained_variance_ratio_)
# উদাহরণ output: [0.72, 0.15]
# মানে: প্রথম নতুন feature original data-র 72% তথ্য ধরে রেখেছে
PCA করার আগেও StandardScaler ব্যবহার করা জরুরি — নাহলে বড় scale-এর feature অন্যায্যভাবে dominate করবে।
