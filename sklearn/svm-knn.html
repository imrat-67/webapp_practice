SVM & K-Nearest Neighbors

দুইটা সম্পূর্ণ ভিন্ন দর্শনের model — একটা "সবচেয়ে ভালো সীমানা (boundary)" খুঁজে বের করে, আরেকটা "কাছের প্রতিবেশী" দেখে সিদ্ধান্ত নেয়।

Support Vector Machine (SVM)

classification
SVC
from sklearn.svm import SVC

দুইটা class-এর মধ্যে এমন একটা সীমানা (boundary/hyperplane) খোঁজে, যেটা দুই class-এর সবচেয়ে কাছের point-গুলো থেকে সর্বোচ্চ দূরত্বে থাকে (Maximum Margin)।

ইনটুইশন: কল্পনা করো, দুই দলের মানুষ একটা মাঠে দাঁড়িয়ে আছে, আর তুমি মাঝখানে একটা দড়ি টানছো তাদের আলাদা করার জন্য। SVM এমনভাবে দড়ি টানে, যাতে দুই দলের **সবচেয়ে কাছের মানুষদের থেকেও** দড়িটা যতটা সম্ভব দূরে থাকে — এতে নতুন কেউ আসলেও ভুল হওয়ার সম্ভাবনা কম থাকে।
Parameterমানে
kernel"linear" (সরলরেখা), "rbf" (বাঁকানো, non-linear সীমানা), "poly"
Cভুল করাকে কতটা penalize করবে (বড় C = কম ভুল সহ্য করে, কিন্তু overfit-এর ঝুঁকি)
from sklearn.svm import SVC

model = SVC(kernel="rbf", C=1.0)
model.fit(X_train, y_train)
predictions = model.predict(X_test)
SVM distance-based, তাই এর আগে অবশ্যই StandardScaler দিয়ে data scale করতে হবে!

K-Nearest Neighbors (KNN)

classificationregression
KNeighborsClassifier
from sklearn.neighbors import KNeighborsClassifier

নতুন একটা data point এলে, তার সবচেয়ে কাছের K-টা data point দেখে, তাদের majority class-ই নতুন point-কে দেওয়া হয়। কোনো "training" আসলে হয় না — শুধু পুরো data মনে রাখা হয় (Lazy Learning)।

ইনটুইশন: "তোমার সঙ্গ দেখে তোমাকে বিচার করবো" — একটা নতুন মানুষ কেমন, বুঝতে তার আশেপাশের ৫ জন বন্ধু কেমন সেটা দেখা।
Parameterমানে
n_neighborsK-এর মান, কয়টা প্রতিবেশী দেখা হবে (default 5)
metricদূরত্ব কীভাবে মাপা হবে — "euclidean" (default), "manhattan"
from sklearn.neighbors import KNeighborsClassifier

model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train, y_train)
predictions = model.predict(X_test)
K ছোট (যেমন 1) vs বড় (যেমন 50): ছোট K → খুব sensitive, noise-এ প্রভাবিত হয় (overfitting)। বড় K → বেশি smooth, কিন্তু খুব বড় হলে সূক্ষ্ম pattern miss করতে পারে (underfitting)।
