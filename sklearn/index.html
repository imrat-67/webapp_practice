scikit-learn // introduction

scikit-learn শিখি, একদম শুরু থেকে

Python-এর সবচেয়ে জনপ্রিয় Machine Learning লাইব্রেরি — বাংলায়, সহজ ভাষায়, প্রতিটা class আর function-এর ইনটুইশন আর কোড উদাহরণসহ।

>>> from sklearn.linear_model import LinearRegression
>>> model = LinearRegression()
>>> model.fit(X_train, y_train)
>>> model.predict(X_test)

scikit-learn আসলে কী?

scikit-learn হলো Python-এর একটা library, যেটা দিয়ে তুমি Machine Learning-এর প্রায় সব ধরনের কাজ করতে পারো — data প্রস্তুত করা, model train করা, prediction করা, আর model-এর performance যাচাই করা।

মূল ইনটুইশন: scikit-learn-এর প্রতিটা model আসলে একটা "কালো বাক্স (black box)" — তুমি তাকে data দিয়ে "শেখাও" (.fit()), আর তারপর সে নতুন data নিয়ে "অনুমান" করে (.predict())। প্রায় সব model-ই এই একই প্যাটার্নে কাজ করে — এটাই scikit-learn-কে শেখা সহজ করে তোলে।

সবচেয়ে গুরুত্বপূর্ণ concept — Estimator API

scikit-learn-এর প্রায় সব class-ই তিনটা method মেনে চলে। এই প্যাটার্নটা একবার বুঝে ফেললে, নতুন যেকোনো model শেখা অনেক সহজ হয়ে যাবে:

Methodকাজ
.fit(X, y)Model-কে training data দিয়ে "শেখানো"
.predict(X)নতুন data-এর জন্য অনুমান (prediction) বের করা
.transform(X)Data-কে রূপান্তর করা (যেমন scaling, encoding — preprocessing-এ ব্যবহার হয়)
# এই প্যাটার্নটা মনে রাখো — এটা প্রায় সব জায়গায় ফিরে আসবে
model = SomeSklearnModel()
model.fit(X_train, y_train)      # ধাপ ১: শেখাও
predictions = model.predict(X_test)  # ধাপ ২: অনুমান করো
