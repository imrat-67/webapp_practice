sklearn.linear_model

Linear Models

সবচেয়ে সহজ, সবচেয়ে ব্যাখ্যাযোগ্য (interpretable) model — একটা সরল রেখা (বা তার generalization) দিয়ে data-এর pattern বোঝার চেষ্টা করে।

Linear Regression — সংখ্যা predict করা (Regression)

regression
LinearRegression
from sklearn.linear_model import LinearRegression

Feature (X) আর একটা continuous output (y, যেমন দাম, তাপমাত্রা)-এর মধ্যে সবচেয়ে ভালো ফিট হওয়া সরলরেখা বের করে: $y = w_1x_1 + w_2x_2 + ... + b$

ইনটুইশন: ধরো, বাড়ির আয়তন (sq ft) দিয়ে দাম predict করছো। Model এমন একটা রেখা খুঁজে বের করে, যেটা সব data point-এর যত কাছ দিয়ে সম্ভব যায় (error, technically MSE, সবচেয়ে কম করে)।
Attribute (fit করার পর)মানে
.coef_প্রতিটা feature-এর "ওজন" (weight/slope)
.intercept_রেখার y-intercept (b)
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X_train, y_train)

print(model.coef_)       # প্রতিটা feature-এর প্রভাব (weight)
print(model.intercept_)  # baseline value

predictions = model.predict(X_test)

Logistic Regression — Category predict করা (Classification)

classification
LogisticRegression
from sklearn.linear_model import LogisticRegression

নাম "Regression" হলেও, এটা আসলে Classification-এর জন্য (যেমন Spam/Not-Spam, Disease/No-Disease)। এটা একটা probability (0 থেকে 1) বের করে sigmoid function দিয়ে, তারপর একটা threshold (সাধারণত 0.5) দিয়ে category ঠিক করে।

মনে আছে Bayes/MLE? Logistic Regression আসলে Maximum Likelihood Estimation দিয়েই সবচেয়ে ভালো weight (coefficient) বের করে — ঠিক তুমি আগে যেভাবে coin bias বের করেছিলে, এখানেও likelihood maximize করা হয়, শুধু parameter অনেক বেশি।
Parameterমানে
CRegularization-এর শক্তি (উল্টো — ছোট C মানে বেশি regularization)
max_iterOptimization কতবার চেষ্টা করবে (default 100, বেশি data হলে বাড়াতে হতে পারে)
from sklearn.linear_model import LogisticRegression

model = LogisticRegression()
model.fit(X_train, y_train)

predictions = model.predict(X_test)          # সরাসরি class (0/1)
probabilities = model.predict_proba(X_test) # প্রতিটা class-এর probability

Regularized Linear Models — Overfitting ঠেকানো

regression
Ridge
from sklearn.linear_model import Ridge

Linear Regression-এর মতোই, কিন্তু বড় coefficient-কে "penalize" করে (L2 penalty), যাতে model খুব বেশি complex না হয়ে যায়।

model = Ridge(alpha=1.0)
model.fit(X_train, y_train)
regression
Lasso
from sklearn.linear_model import Lasso

Ridge-এর মতোই (L1 penalty), কিন্তু এটা কম গুরুত্বপূর্ণ feature-এর coefficient একদম শূন্য করে দিতে পারে — মানে এটা automatic feature selection-ও করে।

model = Lasso(alpha=0.1)
model.fit(X_train, y_train)
মনে রেখো: alpha parameter যত বড়, penalty তত জোরালো — model তত "সরল/conservative" হবে (ঠিক MAP-এ যেমন strong prior model-কে extreme value থেকে টেনে রাখে, এখানেও alpha সেই কাজ করে)।
