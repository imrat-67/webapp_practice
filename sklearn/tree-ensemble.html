Decision Tree & Ensemble Models

একটার পর একটা প্রশ্ন করে (if-else-এর মতো) সিদ্ধান্ত নেওয়া model — আর একাধিক Tree মিলিয়ে আরও শক্তিশালী model বানানো।

Decision Tree

classificationregression
DecisionTreeClassifier / DecisionTreeRegressor
from sklearn.tree import DecisionTreeClassifier

একটা flowchart-এর মতো — প্রতিটা node-এ একটা প্রশ্ন (যেমন "বয়স > 30?"), আর প্রতিটা উত্তর অনুযায়ী পরের node-এ যাওয়া, শেষে একটা leaf-এ পৌঁছে সিদ্ধান্ত নেওয়া।

ইনটুইশন: ঠিক তুমি নিজে যেভাবে সিদ্ধান্ত নাও — "আজকে কি ছাতা নেবো?" → "আকাশ মেঘলা?" → হ্যাঁ হলে → "বৃষ্টির পূর্বাভাস আছে?" → এভাবে ধাপে ধাপে প্রশ্ন করে শেষে একটা সিদ্ধান্তে পৌঁছানো।
Parameterমানে
max_depthTree কত "গভীর" পর্যন্ত প্রশ্ন করবে (বেশি depth = বেশি complex, overfitting-এর ঝুঁকি)
min_samples_splitএকটা node ভাঙতে (split করতে) ন্যূনতম কতগুলো sample দরকার
criterionSplit কীভাবে ঠিক করা হবে — "gini" বা "entropy" (classification-এ)
from sklearn.tree import DecisionTreeClassifier

model = DecisionTreeClassifier(max_depth=4, random_state=42)
model.fit(X_train, y_train)
predictions = model.predict(X_test)
সাবধান: max_depth না দিলে Tree training data একদম মুখস্থ করে ফেলতে পারে (perfect train accuracy কিন্তু খারাপ test accuracy) — এটাই overfitting।

Random Forest — অনেকগুলো Tree-এর "ভোট"

classificationregression
RandomForestClassifier / RandomForestRegressor
from sklearn.ensemble import RandomForestClassifier

একটামাত্র Tree না বানিয়ে, **অনেকগুলো (যেমন ১০০টা) ভিন্ন ভিন্ন Tree** বানানো হয় (প্রতিটা random subset of data/features দিয়ে), তারপর সবার prediction-এর "majority vote" নেওয়া হয়।

ইনটুইশন — "Wisdom of the Crowd": একজন বিশেষজ্ঞের মতামতের চেয়ে, ১০০ জন ভিন্ন ভিন্ন প্রেক্ষাপটের মানুষের majority মতামত সাধারণত বেশি নির্ভরযোগ্য হয়। একটা Tree সহজে overfit করে, কিন্তু ১০০টা ভিন্ন Tree-এর ভুলগুলো একে অপরকে "cancel out" করে ফেলে।
Parameterমানে
n_estimatorsকতগুলো Tree বানানো হবে (default 100)
max_depthপ্রতিটা Tree-এর max depth
n_jobs-1 দিলে সব CPU core ব্যবহার করে parallel-এ train হয়
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(n_estimators=100, n_jobs=-1)
model.fit(X_train, y_train)
predictions = model.predict(X_test)

# কোন feature কতটা গুরুত্বপূর্ণ, সেটাও জানা যায়
print(model.feature_importances_)

from sklearn.ensemble import GradientBoostingClassifier

Random Forest-এর মতো সব Tree একসাথে/independently বানানো হয় না — এখানে প্রতিটা নতুন Tree, আগের Tree-গুলোর ভুলগুলো সংশোধন করার চেষ্টা করে বানানো হয়, ধাপে ধাপে (sequentially)।

from sklearn.ensemble import GradientBoostingClassifier

model = GradientBoostingClassifier(n_estimators=100, learning_rate=0.1)
model.fit(X_train, y_train)
